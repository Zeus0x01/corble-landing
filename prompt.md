

**Prompt:**

Design a modern, high-converting dark-mode AI/SaaS-style landing page for **Corble** inspired by the “Sift” AI SaaS landing page (Dribbble shot by Mahid).

### Overall Visual Style
- Near-black / deep charcoal canvas (`#0a0c10` – `#0e1218`)
- Single sharp **acid-lime / neon green** accent color (`#c8ff00` or `#b8f000`) used sparingly for CTAs, highlights, live indicators, and key numbers
- Soft green glow and subtle ambient lighting behind cards and UI mockups
- Clean, modern sans-serif typography (Inter / SF Pro style)
- Generous whitespace but dense, product-focused information hierarchy
- Card-based modular layout that scales cleanly from desktop to mobile
- Premium, operator-focused, “serious tools for serious people” feeling — not playful or overly rounded

### Structure & Sections (in order)

1. **Sticky Navigation**
   - Dark translucent bar
   - Corble logo (left)
   - Links: Platform / How it works / Pricing / Customers
   - Bright lime “Start Free” button (right)

2. **Hero Section**
   - Big bold headline:  
     **“Decisions, not dashboards.”**  
     (or adapted for Corble: “Automation that actually works.” / “Stop drowning in tools.”)
   - Short supporting text about practical websites + automation systems that save time and grow businesses
   - Two CTAs side-by-side:  
     - Primary solid lime button: “Start Free →”  
     - Secondary ghost button: “Watch 2-min tour”
   - Large product mockup on the right (or below on mobile) showing a clean dark dashboard with live metrics, anomaly alerts, and an AI-drafted action note — all with lime accents
   - Small trust row under the CTAs (e.g. “11 hrs saved / week · 40+ integrations · SOC 2”)

3. **Problem / Positioning Section**
   - Short powerful paragraph:  
     “Every ops team drowns in dashboards nobody reads. Corble is built for operators who don’t want another tool — they want results.”

4. **Modular Feature Cards** (4 cards in a row on desktop, stacked on mobile)
   - Connect
   - Ask / Automate
   - Anomalies / Insights
   - Agents / Workflows  
   Each card has a subtle dark glass effect, lime icon, short title + one-line description.

5. **Product Showcase / Live Demo Feel**
   - Large floating UI cards showing:
     - Live metric cards with lime upward trends
     - Anomaly ping notifications
     - AI-drafted next action notes
   - Soft green ambient glow behind the mockups

6. **Social Proof / Results**
   - Big numbers in lime
   - Short customer quotes or “Trusted by operators at…” logo strip

7. **Final CTA**
   - Dark section with strong lime button and short copy reinforcing the value

### Key Design Rules
- Almost everything is dark — lime is the only strong color
- Use glassmorphism / subtle borders on cards
- Live “pulse” or small status indicators in lime
- Avoid purple, blue, or rainbow accents
- Make it feel like a real product used by operations teams, not a generic AI landing page

Adapt all copy to Corble’s actual offering (practical websites + automation systems that help real businesses work smarter), while keeping the exact visual language, hierarchy, and “decisions over dashboards” energy of the Sift reference.
